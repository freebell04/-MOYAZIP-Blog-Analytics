# 네이버 블로그 도우미

내 블로그 이웃과 소통하고, 블로그 성과를 한눈에 보는 프로그램이에요. 내 컴퓨터에서만 돌아가요.

## 할 수 있는 것

- **이웃 소통**: 내 글에 공감·댓글 남긴 사람, 이웃 목록, 새 글 올린 이웃을 모아보고 답방
  - 카테고리: 실시간 이웃 답방 / 새로운 친구 / 공감·댓글 준 사람 / 이웃 아닌 사람 / 이웃 / 전체
  - [공감하러 가기] → 새 창에서 하트를 누르면 자동으로 "공감 완료" 체크
  - 추천 댓글·답글 예시 + [복사]
  - 답글 안 단 댓글 모아보기
- **성과 통계**: 일별·주별·월별 조회수, 공감·댓글, 유입 경로, 검색어, 인기 글, 시간대, 독자층
  - 글별 초반 성과 (발행 후 3일)
  - 목표(KPI) 설정과 진행 상황
  - 주간 기록 & 회고
  - 다음 콘텐츠 추천 (내 검색어·인기 글 기준)
  - 📥 엑셀 다운로드, 📝 노션에 주간·월간 기록

## 준비물

- Windows PC + **크롬** 브라우저
- **Node.js** (https://nodejs.org 에서 LTS 버전 설치)

## 실행 방법

1. 이 폴더를 원하는 곳에 둡니다 (압축이면 풀어주세요)
2. **`실행하기.bat`** 더블클릭
   - 처음엔 필요한 파일을 자동으로 설치해요 (1~2분)
   - 브라우저에서 http://localhost:3300 이 열려요
3. **처음 설정** 화면에서 내 네이버 블로그 아이디(blog.naver.com/**여기**)와 블로그 이름 입력 → 저장
4. 오른쪽 위 **[네이버 로그인]** → 뜨는 크롬 창에서 **내 네이버 계정**으로 로그인
5. **이웃 소통**에서 [새로 불러오기], **성과 통계**는 열면 자동으로 불러와요

프로그램을 끄려면 검은 창(실행하기)을 닫으면 돼요.

## 노션 기록 (선택)

성과 통계 → **⚙️ 노션 설정**에서 노션 통합 토큰과 저장할 페이지(또는 데이터베이스) 링크를 넣으면,
[📝 노션에 주간 기록] / [📝 노션에 월간 기록]과 주간 회고가 노션에 저장돼요. 설정 화면의 "처음이라면" 안내를 따라 하면 3분이면 돼요.

## 자주 묻는 것

- **"네이버에 로그인되어 있지 않아요"가 떠요** → 네이버 로그인이 풀린 거예요. [네이버 로그인]을 다시 눌러 크롬에서 로그인해주세요.
- **블로그 아이디를 바꾸고 싶어요** → 주소창에 `http://localhost:3300/setup.html` 을 열어서 바꾸면 돼요.
- **공감을 대신 눌러주나요?** → 아니요. 새 창에서 직접 누르면 체크만 해줘요 (자동 공감은 계정 제한 위험이 있어요).

## ⚠️ 개인정보 주의

`data` 폴더에는 **네이버 로그인 정보, 노션 토큰, 내 통계 기록**이 저장돼요.
이 프로그램을 다른 사람에게 줄 때는 **`data` 폴더를 빼고** 주세요.

## 참고

- AI 글쓰기(글쓰기 스튜디오의 AI 글 생성, 추천 댓글의 [✨ AI로 만들기])는 Claude Code가 설치·로그인된 컴퓨터에서만 동작해요. 없어도 나머지 기능은 모두 쓸 수 있어요.
- 네이버 화면 구조가 바뀌면 일부 기능(공감 감지, 이웃 목록)이 동작하지 않을 수 있어요.
