# 네이버 블로그 도우미

내 블로그 이웃과 소통하고, 블로그 성과를 한눈에 보는 프로그램이에요. 내 컴퓨터에서만 돌아가요.

## 할 수 있는 것

- **이웃 소통**: 내 글에 공감·댓글 남긴 사람, 이웃 목록, 새 글 올린 이웃을 모아보고 답방
  - 카테고리: 실시간 이웃 답방 / 새로운 친구 / 공감·댓글 준 사람 / 이웃 아닌 사람 / 이웃 / 전체
  - [공감하러 가기] → 새 탭에서 하트를 누르면 자동으로 "공감 완료" 체크
  - 추천 댓글·답글 예시 + [복사]
  - 답글 안 단 댓글 모아보기
  - **💡 주제 추천**: 이웃들이 최근 30일 동안 쓴 글에서 여러 명이 같이 쓰는 주제·키워드를 찾아 다음 글 주제로 추천 → [이 주제로 글감 찾기]로 바로 글쓰기
- **성과 통계**: 일별·주별·월별 조회수, 공감·댓글, 유입 경로, 검색어, 인기 글, 시간대, 독자층
  - 글별 초반 성과 (발행 후 3일)
  - 목표(KPI) 설정과 진행 상황
  - 주간 기록 & 회고
  - 다음 콘텐츠 추천 (내 검색어·인기 글 기준)
  - 📥 엑셀 다운로드, 📝 노션에 주간·월간 기록

## 준비물

- Windows PC + **크롬** 브라우저
- **Node.js** (https://nodejs.org 에서 LTS 버전 설치)

## 폴더 구성

```
📁 네이버블로그도우미
 ├─ ▶ 실행하기.vbs   ← 이것만 누르면 돼요 (업데이트 확인 + 실행)
 ├─ ■ 종료하기.vbs   ← 끌 때
 ├─ README.md
 └─ 📁 app           ← 프로그램 본체 (건드릴 필요 없어요)
     └─ 📁 data      ← 로그인 정보·설정·통계 (처음 실행하면 생겨요)
```

## 사용 키

처음 켜면 **사용 키 입력** 화면이 나와요. 체험단 선정 안내나 구매 안내로 받은 키(NBH-로 시작)를 붙여넣으면 바로 쓸 수 있어요.
키에는 사용 기간이 들어 있어서, 기간이 끝나면 다시 키 입력 화면으로 돌아가요.

## 실행 방법

1. 이 폴더를 원하는 곳에 둡니다 (압축이면 풀어주세요)
2. **`실행하기.vbs`** 더블클릭
   - 창 없이 로딩 화면(N 배지) → 실제 화면 순서로 브라우저가 열려요
   - **새 버전은 뒤에서 알아서 받아두고, 다음에 켤 때 자동으로 적용**돼요 (따로 업데이트할 필요 없고, 기다리지도 않아요)
   - 로딩 화면에서 지금 어느 단계인지 한눈에 보여요. 문제가 생기면 그 화면에 이유가 떠요
   - 평소엔 2~3초면 켜지고, 이미 켜져 있을 땐 누르자마자 바로 열려요
   - 처음 켤 때는 필요한 파일을 뒤에서 설치해서 몇 분 걸릴 수 있어요
   - Node.js가 없거나 설치가 실패하면 로딩 화면에 안내가 떠요
3. **처음 설정** 화면에서 내 네이버 블로그 아이디(blog.naver.com/**여기**)와 블로그 이름 입력 → 저장
4. 오른쪽 위 **[네이버 로그인]** → 뜨는 크롬 창에서 **내 네이버 계정**으로 로그인
5. **이웃 소통**에서 [새로 불러오기], **성과 통계**는 열면 자동으로 불러와요

프로그램은 화면에 안 보이는 상태로 계속 켜져 있어요. **끄고 싶으면 `종료하기.vbs`**를 더블클릭하면 돼요.
새 버전을 바로 쓰고 싶으면 `종료하기.vbs` → `실행하기.vbs` 순서로 다시 켜면 돼요.

## 노션 기록 (선택)

성과 통계 → **⚙️ 노션 설정**에서 노션 통합 토큰과 저장할 페이지(또는 데이터베이스) 링크를 넣으면,
[📝 노션에 주간 기록] / [📝 노션에 월간 기록]과 주간 회고가 노션에 저장돼요. 설정 화면의 "처음이라면" 안내를 따라 하면 3분이면 돼요.

## 자주 묻는 것

- **"네이버에 로그인되어 있지 않아요"가 떠요** → 네이버 로그인이 풀린 거예요. [네이버 로그인]을 다시 눌러 크롬에서 로그인해주세요.
- **블로그 아이디를 바꾸고 싶어요** → 주소창에 `http://localhost:3300/setup.html` 을 열어서 바꾸면 돼요.
- **공감을 대신 눌러주나요?** → 아니요. 새 탭에서 직접 누르면 체크만 해줘요 (자동 공감은 계정 제한 위험이 있어요).
- **껐다가 다시 켜고 싶어요** → `종료하기.vbs` → `실행하기.vbs` 순서로 누르면 돼요.
- **잘 켜졌는지/오류가 있었는지 확인하고 싶어요** → `app` 폴더 안에 생기는 `server.log` 파일에서 볼 수 있어요.

## ⚠️ 개인정보 주의

입력칸에 쳤던 검색어를 브라우저가 기억해서 목록으로 보여주지 않도록 꺼두었어요 (같은 컴퓨터를 쓰는 사람에게 내 검색어가 보이지 않게).


`appdata` 폴더에는 **네이버 로그인 정보, 노션 토큰, 내 통계 기록**이 저장돼요.
이 프로그램을 다른 사람에게 줄 때는 **`appdata` 폴더를 빼고** 주세요.

## 참고

- AI 글쓰기(글쓰기 스튜디오의 AI 글 생성, 추천 댓글의 [✨ AI로 만들기])는 Claude 구독이 있어야 해요. 처음 쓸 때 "로그인하지 않았어요"가 뜨면 [Claude 로그인 창 열기]를 눌러 한 번만 로그인하면 돼요. 없어도 나머지 기능은 모두 쓸 수 있어요.
- **📐 내 블로그 글 형식**: 글감을 검색하면 나오는 2단계에서 [Claude/ChatGPT/Gemini로 분석]을 누르면, 내 블로그 최근 글 3개를 AI가 분석해서 제목·말투·구성·마무리 방식을 저장해요 (`appdatalog-format.json`, 내 컴퓨터에만). 이후 초안은 그 형식을 따라 써져요. 분석 전 기본값은 자유 형식이에요. 저장된 형식은 화면에서 보고 직접 고칠 수 있어요.
- **AI와 대화하면서 쓰기**: 글감을 체크하고 평소 쓰는 AI 버튼을 누르세요.
  - **🤖 Claude / 💬 ChatGPT / ✨ Gemini** 중 하나를 누르면 → 네이버 로그인용 크롬에 그 AI 채팅이 새 탭으로 열리고 요청문이 자동으로 들어가요 → AI가 방향을 먼저 물어봐요 → 그 탭에서 초안을 다듬고 "완성"이라고 보내면 → 앱이 결과를 알아채서 네이버 글쓰기 창을 열고 내용을 채워요
  - 각 AI는 그 크롬에서 **처음 한 번만 로그인**하면 돼요 (로그인 화면이 뜨면 로그인하세요, 로그인하면 요청문이 자동으로 들어가요)
  - 자동 입력이 안 될 땐 화면의 요청문을 [복사]해서 붙여넣고, 결과 JSON을 [결과 붙여넣기]에 넣으면 돼요
- 네이버 화면 구조가 바뀌면 일부 기능(공감 감지, 이웃 목록)이 동작하지 않을 수 있어요.
